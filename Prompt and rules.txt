# MASTER DEVELOPMENT PROMPT — NASC ASSESSMENT PORTAL PROTOTYPE

Act as a senior full-stack software architect, UI/UX designer, database architect, QA engineer, and higher-education assessment-system specialist.

Build a functional prototype called:

**NASC Assessment Portal**

Institution:
**Nehru Arts and Science College (Autonomous)**

The system is intended to digitize and centralize academic assessment activities including internal assessments, assignments, quizzes, practical assessments, question banks, evaluation, marks, OBE/CO attainment and academic analytics.

The prototype must look like a real institutional product suitable for demonstration to college management.

---

# 1. CORE DESIGN PRINCIPLE

DO NOT create separate applications or separate portals for students, faculty, HoDs, coordinators and administrators.

Build:

**ONE APPLICATION**
**ONE LOGIN PAGE**
**ONE DATABASE**
**ONE CONSISTENT UI**

Different users log in through the same authentication page.

After authentication, the system identifies their role and dynamically displays the features, data and permissions available to that role.

Example:

Student Login
→ Student Dashboard

Faculty Login
→ Faculty Dashboard

HoD Login
→ Department Dashboard

Administrator Login
→ Administration Dashboard

The URL structure, application and design system remain unified.

Implement Role-Based Access Control (RBAC).

Roles for prototype:

1. Student
2. Faculty
3. Class Tutor
4. HoD
5. Assessment Coordinator
6. Administrator

Allow a user to have multiple roles where required.

# 48. FIRST DEVELOPMENT TASK

Before writing large amounts of code:

1. Inspect the existing repository.
2. Create the application architecture.
3. Design the database schema.
4. Create the navigation architecture.
5. Define RBAC permissions.
6. Define API modules.
7. Define frontend pages.
8. Prepare seed data.
9. Create a development plan.
10. Then implement the prototype incrementally.

Do not rewrite functioning project infrastructure unnecessarily.

After each major module:

Run the application.
Check backend errors.
Check browser console errors.
Test APIs.
Test database persistence.
Test role permissions.
Fix errors before continuing.

The final result should be a functional, visually polished prototype of the **NASC Assessment Portal** capable of demonstrating how Nehru Arts and Science College could centrally manage its academic assessment lifecycle.
